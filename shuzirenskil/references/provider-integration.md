# 按接口文档接入模型（2026-10-24）

同名模型在不同服务商不等于同一协议。新增模型先核对服务商文档，再改代码与测试；不得仅替换模型名或扩大域名白名单。

## 每次接入的最小清单

1. 记录官方/服务商文档链接、核对日期、准确模型 ID、API 版本与主机。
2. 分别确认创建/查询/下载的路径、方法、认证、超时语义，异步或同步响应；未实现的协议明确拒绝。
3. 核对请求字段的名称与类型，包括时长、分辨率、画幅、图片角色和音频；能力按模型及输入模式登记，不继承另一版本的范围。
4. 核对图片、音频、视频是 HTTPS、Data URI、文件 ID 还是 inlineData；上传成功与上游读取成功分别记录。不能自动上传到临时图床，也不能自行假设支持 Base64。文件 ID 需要相应上传与有效期协议，未接入就拒绝。
5. 从创建成功示例确定任务编号的精确路径。追踪号只有在该接口明确把它用作任务编号时才可查询；不能递归寻找任意 id。失败响应必须先识别，不把其中的 request_id 当作任务。
6. 分别登记排队、运行、完成、失败、取消、过期状态与媒体字段；未登记状态停止并保留原编号，不假装完成，也不重发。
7. 测试至少包含文档成功示例、业务错误、HTTP 502、超时、缺号、完成但缺媒体、图片过期/即将到期、取消/失败、下载认证与跨域不转发凭据。离线测试通过后，真实首段按原有制作授权执行；未做真实测试必须保留待验证状态。

## 代码入口

- `assets/model-registry.json`：准确模型、能力范围、来源与验证状态。
- `scripts/request_preview.py`：各模型请求字段及素材角色，不能共用一份泛化 payload。
- `scripts/provider_contract.py`：各服务商任务编号、状态、图片传输规则；未知服务商无默认规则。
- `scripts/studio_transport.py`：认证、创建/查询/下载及脱敏网络诊断。
- `scripts/studio_assets.py`：素材一致性、到期余量和本机可读检查。

## 图片 URL 与有效期

HTTPS 图片默认要求至少剩余 1800 秒，可在该素材绑定中设置更大的 `min_remaining_seconds`。这是本地运行保护值，不是服务商 SLA，也不保证排队永远短于该时间。长队列按服务商文档延长有效期；每次提交前重新检查。失败发生在素材准备时，记录尚未发送视频 POST；可以修正素材后继续，不能把它记成生成失败。

AI 跃云图片目前仅有公开图片成功的用户反馈，Data URI 未完成协议验证，因此仅允许绑定的 HTTPS 图片，不套用 91topgo 的 JPEG Data URI。Grok 的 15 秒纯文字实测不代表参考图模式已验收。其完整图片接口文档取得后，再扩展传输模式。

本机 GET 成功和文件指纹一致只证明本机可读；无服务商抓取日志/检查接口时，上游可读性仍标为未验证。不要据此声称“图片没有问题”。

## 诊断及恢复

新入口分别保存素材准备阶段和视频提交阶段。HTTP 诊断记录方法、主机、耗时、HTTP 状态及响应头追踪号；正文任务编号单独保存。错误内容按白名单脱敏，不保留私人素材 URL 的签名或密钥。POST 结果未知只查询/人工恢复原任务，不自动重发。旧入口保留原流程和已有诊断；不要把新入口的完整诊断能力宣称为旧入口已全部具备。
