# 数字人口播制作方案模板

方案的声音部分必须按 `voice-casting-and-text-review.md` 设计角色专属声线：列出角色用途、造型依据、共鸣、声音质地、咬字和应避免的声音。图片只能辅助创作选角，不证明真实声音。出图后实际看图核对，并在原定图片确认时展示简明声音说明。


## 当前材料

列出主题、稿件、文档、PPT、人物图、音频、字幕和视频。分别说明它控制事实、人物、内容、时长、声音还是风格；无法读取或互相冲突的材料要明确指出。

## 内容检查

用普通语言说明事实依据、逻辑、口语表达、平台风格、预计时长和风险。材料有事实要求时附简短事实表。不得把未知内容补成事实。

## 完整口播稿

提供用户能直接朗读的最终全文。主题清楚时直接给出合理角度与完整方案；只有内容方向确实缺少关键条件时才先询问。
根据 `duration-planning.md` 先区分用户目标、用户上限和内容推算，再注明稿件是 AI 自写、可改写还是逐字锁定。AI 自写稿先确定受众和唯一主张，写成有信息增量的短句；使用 `plan` 检查，过短补充具体价值，过长删重复。给出中文汉字数、英文词数、目标语速、预计朗读秒数与请求秒数。不能为填充时间制造事实、重复空话或改成慢读；不能擅自缩短用户指定时长。

## 视觉方案

说明人物外观、服装、场景、景别、镜头运动、表情和动作。默认画面中没有任何文字元素。先选择生成模式：需要固定第一帧时使用 `image-to-video`；需要把人物、服装、产品或场景分别锁定时使用 `reference-to-video`。列出每张 Image2 或用户图片的用途、顺序、父图关系和是否会进入视频请求。多参考图时总数不超过 7，每张图只分配一个主要职责，且至少一张是 `identity`。分镜图默认只预览，不进入视频请求。

同时列出视频提示词合同：参考图映射、连续性、视觉质感、镜头、人物表演、完整台词、声音设计、时间节奏和强制限制。不要只给一段堆砌形容词的提示词。
按每段真实台词列出至少一个表演节拍：在哪个短语轻微改变表情；手势仅在确有强调价值时设置，15 秒通常一处主手势足够，做完自然回位。避免“始终微笑、始终稳定、全程少动”这类会让人物僵住的指令，也避免把静态“双手放桌上”写成手势。

## 时长和分段

明确用户目标、上限或内容推算三种来源，并使用 `plan` 的结果：逐段列出台词、估计朗读秒数、请求秒数、总次数、预计交付时长和允许误差。`exact` 对应用户目标；`content-fit` 对应未指定或只有上限的任务。每段最多 15 秒，不强制补满；按完整句子分配秒数，例如合理的 20 秒方案可为 `10+10`。用户提供的稿件与指定时长冲突时，给出具体改稿方案或自然时长选项；AI 草稿则先自行调整再交用户确认。
“前 3 秒提问、中间 9 秒讲用途”等精确秒数只适合已锁定音频后的视觉分镜，不得放进模型生成口播的 `speech_delivery`。口播只规定大致语速、发音和随句意自然停顿，不要求模型靠拖长停顿匹配时间。

注意：完整句子数量不等于片段数量。先在自然语义处补充句号，再把相邻完整句子合并到不超过约 14.4 秒的片段中。比如 19 秒三句稿可为“前两句一段、最后一句一段”，必须明确写出 2 个片段，不能按 3 个句号生成 3 个任务。

多段时还要逐项写明固定的人物身份、服装、场景、机位、灯光和动作范围。提示词人声默认复用同一张主参考图，列出结构化声音特征和 `voice_signature`；同时明确这只能降低漂移，不能保证声音、口型和跨段动作完全一致。

## 模型和费用

- 模型：两家服务商均使用 `grok-imagine-video-1.5`；`grok-imagine-video-1.5-preview` 只记录为官方别名，不自动改写或重试
- 接口：默认 91topgo 使用 `POST /v1/videos`；仅在提交前显式降级时，MikuAPI 使用 `POST /v1/videos/generations`
- 状态：当前 91topgo 已有 1 秒纯文本链路和参考图跨 Skill 验收；MikuAPI 有 4 秒和 15 秒单图短片验收。两者都不能据此承诺本次长句逐字准确或跨段连续性
- 生成模式：`image-to-video` 或 `reference-to-video`，两者不能混用
- 输入传输：91topgo 可使用已确认本地图片的 JPEG Data URI；MikuAPI 只使用已确认的公共 HTTPS 单图，Files API 已实测返回 HTTP 404
- 声音：默认 `prompt_generated_voice`，列出性别听感、年龄感、音高、音色、语速、情绪、发音、口音和 `voice_signature`；需要预设声音时列出 `voice_id`。用户自己的音频没有可信合作方权限和中转站验收时不上传，也不承诺保留原音色
- 基础付费次数：等于片段数
- 最高付费次数：等于片段数
- 自动重试次数：0
- 多段执行顺序：先提交第 1 段，按正常速度完整看听并通过 `review-pilot` 后才提交剩余已授权片段；首段效果差时停止，避免继续花费

## 字幕和后期

字幕默认关闭。若启用，说明先检查干净视频，再由本机 Whisper 和 FFmpeg 制作；字幕不会发给视频模型。额外音乐、转场和素材默认关闭，除非用户明确选择。

## 停止条件

接口状态不明、合同变化、任务明确失败、素材权利不清、重要事实未确认、成片缺字、人物严重变化或拼接无法修复时停止。不会自动再次扣费。

## 请确认方案

说明本次确认只授权第三方 `gpt-image-2` 生成所列生产图片，不授权图片上传或付费视频。确认后 Skill 会直接生图，不再询问“是否生图”。图片生成后，用户只需再确认实际图片并明确开始制作；这条回复同时授权方案中已披露的短期图片上传、免费预检、已披露次数内的视频生成、裁剪、拼接、质检和交付，不得再要求第三次确认。
